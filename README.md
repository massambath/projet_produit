📱📦 Application de Gestion de Produits
📌 Description

Ce projet est une application de gestion de produits développée dans le cadre de la 2ᵉ année du cycle ingénieur à l’ESMT.
Il combine une application mobile avec un backend Java REST permettant la gestion des produits et du stock.

🛠️ Technologies

Backend : Java, Spring Boot

Persistance : JPA / Hibernate

Base de données : MySQL

Mobile : Android (Java)

Outils : Git, Maven, Postman

🚀 Fonctionnalités

Ajouter un produit

Lister les produits

Modifier un produit

Supprimer un produit

Gestion du stock

🔌 API REST

POST /produits : ajouter un produit

GET /produits : liste des produits

PUT /produits/{ref} : modifier un produit

DELETE /produits/{ref} : supprimer un produit
